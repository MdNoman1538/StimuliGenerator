# ImagenAndDescriptionV1

A guideline-driven system for generating semantic text and image stimuli with large language models, intended for use in design ideation research.

This repository is the implementation artefact accompanying the master's thesis *Semantic Stimuli Generation with Large Language Models: A System for Augmenting Design Creativity* (Md Abdullah Al Noman, supervised by Dr. Georgi Georgiev, University of Oulu).

## What it does

Given a design task description and a list of requirements, the system produces:

- **Three text stimuli**, generated by a single LLM call (Gemini), parsed and validated against an inventory of concrete nouns derived from Brysbaert et al.'s concreteness ratings.
- **Three paired text-and-image stimuli**, where each text description is passed through a second prompt template and rendered by an image model.

Every generation is appended to a JSONL log together with the full prompt, model identifier, parameters, and timestamp, so that any stimulus set can be regenerated or audited.

## Architecture

| Module | Role |
| --- | --- |
| `main.py` | FastAPI entry point and CORS configuration |
| `routes.py` | Request/response schemas and the generation endpoint |
| `system_prompt.py`, `image_system_prompt.py` | Guideline layer that wraps every LLM and image call |
| `gemini_client.py` | Google Gemini API abstraction with timeout handling |
| `image_generator.py` | Paired-image generation pipeline |
| `parser.py`, `noun_validator.py` | Extract and validate the three stimuli returned by the LLM |
| `semantic_analyzer/` | Noun and concreteness analysis using Brysbaert ratings |
| `logger.py` | JSONL session logging for reproducibility |
| `config.py` | Single source of truth for paths, models, and constants |

## Setup

```bash
git clone https://github.com/<your-username>/ImagenAndDescriptionV1.git
cd ImagenAndDescriptionV1

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m spacy download en_core_web_sm

cp .env.example .env
# edit .env and set GEMINI_API_KEY=...
```

## Run

```bash
uvicorn main:app --reload
```

Open `http://localhost:8000` in a browser.

## Data in this repository

- `generated_images/` — images produced during the thesis evaluation runs
- `exports/` — text exports of stimulus sets
- `generation_log.jsonl`, `stimuli_log.jsonl`, `image_gen_timings.jsonl` — full session logs
- `semantic_analyzer/` — concreteness lookup data (Brysbaert et al.)

The duplicate `image_backups/` folder is excluded from the repository to keep the clone size manageable; images can be regenerated from the JSONL logs.
